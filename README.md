# FitBuddy

AI Fitness Plan Generator using Google Gemini AI.

## Features
- Generate a 7-day general fitness plan
- Nutrition and recovery tips
- Update plans using feedback
- Admin dashboard
- SQLite database

## Run the Project

Install requirements:

pip install -r requirements.txt

Run the application:

uvicorn main:app --reload

Open in browser:

http://127.0.0.1:8000
